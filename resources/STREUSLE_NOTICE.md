# STREUSLE 5.0 offline benchmark notice

This project records an offline evaluation profile for STREUSLE 5.0, created by
Nathan Schneider and collaborators: <https://github.com/nert-nlp/streusle>.

The upstream MWE, supersense, and redistributed UD annotations are offered under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The upstream
README states that the English Web Treebank review sentences and PTB annotations
are redistributed with permission of Google and the Linguistic Data Consortium,
respectively. Consult the upstream `README.md`, `LICENSE.txt`, `FORMAT.md`, and
acknowledgments before using or sharing the corpus.

No STREUSLE corpus text, model, or source code is copied into this repository.
The local profile contains artifact identities, project-derived counts, a
category projection, and conservative use limits. The IR-130 mapping queue also
retains a modified subset of 146 canonical `V.VID` annotation labels, assigns
new opaque project IDs, and adds project-authored source-route states. That
subset remains under CC BY-SA 4.0 and is not a substitute for the corpus or its
source-text/PTB permission notices. It is not endorsed by the STREUSLE
creators, Google, LDC, UD, or PARSEME.
